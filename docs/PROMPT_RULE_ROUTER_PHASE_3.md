# Prompt Rule Router — Phase 3

## Principle

The router never forces one creative template onto every project. Explicit menu selections, uploaded references, the current script, user instructions and locked Context IR are binding facts. The router only resolves which implementation rules apply and which contradictory generic prose must be suppressed.

Source precedence begins with uploaded/user reference truth, explicit menu selections, approved/current script facts and locked Context IR. A camera preference, generic negative or legacy example cannot replace those facts.

## Hook selection

- A hook is required when an explicit menu choice asks for immediate attention: an attention/retention audience goal, a short-insight format, or a marketing-led video goal.
- Hook form is not prescribed. It may be sensory, emotional, factual, narrative or product proof according to the selected format and story.
- Other combinations are intent-gated. Observational, visual-poem, empathy, reflection and narrative work are not automatically converted into clickbait.
- The legacy global “clip 1 always has a 3–5 second hook” rule is suppressed in both branches.

## Clip continuity versus editing

These are different scopes, not mutually exclusive styles:

- inside one generated clip: one physically continuous take protects keyframe-to-video motion from morphing and teleporting;
- between clips: Context IR owns continuous, scene cut, montage, match cut, time jump, parallel, dream or symbolic transitions.

Only a declared continuous boundary inherits the complete prior physical state. Other modes preserve only their declared anchors.

## Camera selection

The locked production profile already compiles genre, subtype, directing menu and custom camera instruction. Context IR camera grammar and edit rhythm therefore outrank generic prose such as “always smooth” or “always vary the move”. Static, POV, handheld, rhythmic, documentary, technical and other selected grammars remain distinct.

## Action budget

The exact Context IR action budget is binding. Without one, action remains Scene-Intent-led and physically conservative. Decorative hand business is never mandatory, and intentional stillness is valid when it serves performance or intent.

## Activation and rollback

Phase 3 is disabled by default. Set `PROMPT_RULE_ROUTER_V3=true` to activate it. `PROMPT_RULE_ROUTER_V2` remains a temporary compatibility alias. Unset both variables to return the unchanged legacy system prompt.
