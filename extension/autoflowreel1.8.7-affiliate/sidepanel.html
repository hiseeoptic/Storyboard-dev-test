Thiết lập phần tử

Click "Teach" rồi click vào phần tử tương ứng trên trang Flow để gán. Mẹo: mở panel "Thêm vào câu lệnh" rồi bấm "🔍 Quét UI" để chụp cấu trúc gửi dev.

🎯 What is DOM Setup?

DOM Setup teaches the extension WHERE to find elements on Google Flow. Since Google updates their UI frequently, you need to manually map each element once so the extension can interact with it.

📋 How to Teach
  1. Open Google Flow (labs.google.com/fx) in a Chrome tab
  2. Open this extension's side panel
  3. Go to the "Cài đặt DOM" (Setup) tab
  4. Click the "Teach" button next to the element you want to map
  5. The page will show a blue overlay — click the matching element on the Flow page
  6. The status changes to ✅ mapped when successful
  7. Repeat for all elements. You need at least: Prompt Input, Submit Button

🎯 DOM Setup là gì?

DOM Setup dạy extension BIẾT tìm các phần tử ở đâu trên trang Google Flow. Vì Google thường cập nhật giao diện, bạn cần gán thủ công mỗi phần tử một lần để extension tương tác được.

📋 Cách Teach (Dạy)
  1. Mở Google Flow (labs.google.com/fx) trong tab Chrome
  2. Mở side panel của extension này
  3. Vào tab "Cài đặt DOM"
  4. Bấm nút "Teach" bên cạnh phần tử muốn gán
  5. Trang hiện lớp phủ xanh — bấm vào phần tử tương ứng trên trang Flow
  6. Trạng thái đổi thành ✅ đã gán khi thành công
  7. Lặp lại cho tất cả. Tối thiểu cần: Ô nhập Prompt + Nút Submit

📖 Storyboard AI Guide

Create professional storyboards with AI assistance

01 Story & Script
  1. Open the Storyboard AI app from the AI tab
  2. Enter your story concept or paste a full script
  3. AI analyzes your story and prepares scene breakdowns
  4. Review the generated scenes before proceeding
02 Characters & Products
  1. Define your characters with descriptions and traits
  2. Upload reference images for visual consistency
  3. Add product placements if needed for commercial content
  4. AI ensures characters stay consistent across all scenes
03 Background & Style
  1. Choose background settings for your scenes
  2. Select a visual style (cinematic, anime, realistic, etc.)
  3. AI generates storyboard images matching your style
04 Generate & Export
  1. Click "Generate" to create your storyboard
  2. Review all generated scenes and images
  3. Export as PDF or ZIP for your production team
  4. Re-generate individual scenes if needed
💡 Pro Tips
  • Be specific with character descriptions for better consistency
  • Use reference images whenever possible
  • Short, clear scene descriptions produce better results
  • Export PDF for client presentations, ZIP for production
  • You can regenerate individual scenes without affecting others
❓ FAQ
What AI model is used?

Uses advanced AI models for text and image generation. API keys are secured server-side.

Can I use my own images?

Yes! Upload reference images for characters and backgrounds to ensure consistency.

What export formats are available?

PDF for presentations and ZIP with individual scene images for production use.

📖 VeoFlow User Guide

Complete guide to create professional video prompts

01 Script & Prompt
  1. Open "1. Script & Prompt" from the left sidebar
  2. Choose a visual style (Cinematic 8K, Realistic Life, etc.)
  3. Paste your full script — separate scenes with blank lines
  4. Click "INIT PROJECT DNA" → AI creates Master Manifest
  5. Wait for green "DNA LOCKED" indicator
  6. Click "ANALYZE SCRIPT" → AI splits into 8-sec clips
  7. Click "RESUME GENERATION" → creates Veo 3 prompts
  8. Each clip shows PASS ✅ or VIOLATION ❌. Click to expand
  9. Use "FORCE STOP" to halt mid-generation
02 Characters
  1. Open "2. Characters" tab
  2. Enter characters: Name | Hair | Outfit | Voice
  3. Example: Sarah | Long brown hair | Red dress | soft_trust
  4. Click "SYNC CHARACTER DATABASE"
  5. Upload reference images (+ button) to lock faces
  6. Characters auto-referenced in all generated prompts
03 Export & AutoFlow
  1. Open "3. Export Prompts" to see completed clips
  2. COPY ALL PROMPTS — all prompts to clipboard
  3. EXPORT .TXT / .JSON — download files
  4. PUSH TO AUTOFLOW — sends to this extension's Queue
  5. AF JSON — copy AutoFlow-compatible JSON
  6. Individual clips have COPY PROMPT & JSON buttons
💡 Pro Tips
  • Each paragraph = one 8-second clip
  • Use character names matching your Character Database
  • Re-init DNA if you make major script changes
  • Failed clips can be regenerated individually (refresh icon)
  • Choose visual style BEFORE generating for best results
  • AutoFlow = script → prompts → video without manual copy
❓ FAQ
What AI model?

GPT-4o for all processing. API key secured on Vercel.

How long per clip?

8 seconds, optimized for Veo 3 Flow on Google Labs.

What is Master Manifest?

A DNA lock ensuring character, environment & camera stay consistent across all clips.

How does AutoFlow work?

VeoFlow creates prompts → pushes to extension → extension auto-submits to Google Flow.

📖 Hướng Dẫn Sử Dụng VeoFlow

Hướng dẫn đầy đủ tạo prompt video chuyên nghiệp

01 Script & Prompt — Viết Kịch Bản
  1. Mở tab "1. Script & Prompt" từ thanh bên trái
  2. Chọn phong cách (Cinematic 8K, Realistic Life, v.v.)
  3. Dán kịch bản — ngăn cách cảnh bằng dòng trống
  4. Bấm "INIT PROJECT DNA" → AI tạo Master Manifest
  5. Chờ đèn xanh "DNA LOCKED"
  6. Bấm "ANALYZE SCRIPT" → AI chia thành clip 8 giây
  7. Bấm "RESUME GENERATION" → tạo prompt Veo 3
  8. Mỗi clip hiện PASS ✅ hoặc VIOLATION ❌. Bấm để xem chi tiết
  9. Dùng "FORCE STOP" để dừng giữa chừng
02 Characters — Thiết Lập Nhân Vật
  1. Mở tab "2. Characters"
  2. Nhập nhân vật: Tên | Tóc | Trang phục | Voice
  3. Ví dụ: Mai | Tóc dài nâu | Đầm đỏ | soft_trust
  4. Bấm "SYNC CHARACTER DATABASE"
  5. Tải ảnh tham khảo (nút +) để khóa ngoại hình
  6. Nhân vật tự động xuất hiện trong mọi prompt tạo ra
03 Export & AutoFlow — Xuất Kết Quả
  1. Mở tab "3. Export Prompts" xem clip hoàn thành
  2. COPY ALL PROMPTS — sao chép tất cả vào clipboard
  3. EXPORT .TXT / .JSON — tải file
  4. PUSH TO AUTOFLOW — gửi thẳng vào Queue extension
  5. AF JSON — sao chép JSON tương thích AutoFlow
  6. Từng clip có nút COPY PROMPT & JSON riêng
💡 Mẹo Hay
  • Mỗi đoạn văn = 1 clip 8 giây
  • Tên nhân vật trong kịch bản phải khớp Character Database
  • Khởi tạo lại DNA nếu thay đổi kịch bản lớn
  • Clip lỗi tạo lại riêng bằng nút refresh, không ảnh hưởng clip khác
  • Chọn phong cách TRƯỚC khi tạo clip để kết quả tốt nhất
  • AutoFlow = kịch bản → prompt → video không cần copy thủ công
